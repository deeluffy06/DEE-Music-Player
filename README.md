#DEE Music Player
##Overview

A custom ESP32 based portable music player capable of

Playing MP3 files from SD Card
Streaming music through WiFi
Bluetooth Audio
OLED UI
Rotary Encoder Navigation
Battery Monitoring
USB-C Charging
Future OTA Updates

###Hardware
ESP32 Dev Board
MAX98357A I2S Amplifier
3W Speaker
OLED Display
Rotary Encoder
SD Card Module
Li-ion Battery
TP4056 Charging Module

###Features
SD Card Playback
WiFi Streaming
Bluetooth Speaker
Battery Percentage
Volume Control
Playlist Support
Album Art (Future)
Equalizer (Future)

###Future Plans
Spotify Connect
OTA Firmware Updates
Touch Screen
Bluetooth LE App
